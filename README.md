TripTales — Desktop Travel & Adventure Landing Page
A full-width, immersive travel web experience designed for desktop displays. 
It features a rich tropical hero backdrop with framed scenery, floating action buttons, a horizontal 3-column value proposition bar, a 3-card trending destination grid, a 4-column feature list, an editorial travel guide showcase, and a full-width call-to-action banner. 
Built with responsive layout hierarchy, modern typography, and clean vector visuals optimized for high-resolution screens.

TripTales — Mobile Travel & Adventure Landing Page (390px)

A streamlined, single-column mobile landing page tailored for smartphone screens ($390\text{px}$ breakpoint).
It translates the full desktop UI into a compact, thumb-friendly layout featuring a collapsible hamburger navigation header, stacked action buttons, a compact 2x2 feature grid, vertically stacked destination and article cards, and touch-optimized call-to-action banners. 
Perfect for mobile-first web experiences and fast browsing on the go.
